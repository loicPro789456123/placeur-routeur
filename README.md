# Placeur-routeur

Placeur-routeur automatique de circuits imprimes (Rust + controles Python), en cours de developpement.
Le dossier `PCB_V2/outils/placeur_routage` contient le programme et une carte d'essai.
Les campagnes de test (une graine par machine) sont lancees par `.github/workflows/placeur.yml`;
les resultats arrivent sur la branche `ci-resultats-placeur`.
